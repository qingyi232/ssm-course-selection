课程封面图片目录
================

将课程封面图片（PNG/JPG/JPEG格式）放入此目录。

使用方法：
---------
1. 将图片文件放入此目录，如：java.png、database.jpg
2. 在数据库course表的cover_image字段填入路径：images/covers/文件名
   例如：images/covers/java.png

图片命名建议：
-------------
java.png        - Java程序设计
database.png    - 数据库原理
web.png         - Web前端开发
software.png    - 软件工程
python.png      - Python程序设计
network.png     - 计算机网络
os.png          - 操作系统
datastructure.png - 数据结构
ai.png          - 人工智能
default.png     - 默认封面

图片尺寸建议：400x300像素或16:9比例

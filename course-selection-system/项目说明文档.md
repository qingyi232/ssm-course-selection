# 基于Java的在线课程选课系统 - 项目说明文档

## 一、项目概述

### 1.1 项目简介
本系统是一个基于Java Web技术开发的在线课程选课系统，采用B/S（浏览器/服务器）架构，为高校师生提供便捷的课程管理与选课平台。系统实现了学生选课、教师课程管理、管理员系统管理等核心功能，并新增了课程评价、选课历史记录、成绩统计图表、课程收藏等增值功能，提供完整的教学管理解决方案。

### 1.2 技术栈
| 技术 | 说明 |
|------|------|
| 后端语言 | Java 8+ |
| Web框架 | Servlet + JSP |
| 数据库 | MySQL 5.7+ |
| 服务器 | Apache Tomcat 9.0 |
| 前端技术 | HTML5 + CSS3 + JavaScript |
| 图表库 | Chart.js（成绩统计可视化） |
| 构建工具 | Maven |
| 开发工具 | IntelliJ IDEA |

## 二、环境配置与部署

### 2.1 环境要求
- **JDK**: 1.8 或更高版本
- **MySQL**: 5.7 或更高版本
- **Tomcat**: 9.0 或更高版本
- **Maven**: 3.6 或更高版本（用于构建项目）

### 2.2 数据库配置

#### 步骤1：创建数据库
打开MySQL命令行或Navicat等工具，执行以下操作：

```sql
-- 方法：直接执行sql文件
source /path/to/course-selection-system/sql/init.sql
```

#### 步骤2：修改数据库连接配置
打开文件：`src/main/java/com/course/util/DBUtil.java`

```java
// 修改以下配置为你的数据库信息
private static final String URL = "jdbc:mysql://localhost:3306/course_selection?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8";
private static final String USERNAME = "root";      // 你的MySQL用户名
private static final String PASSWORD = "root";      // 你的MySQL密码
```

### 2.3 项目部署

#### 方法：使用IDEA运行
1. 用IDEA打开项目
2. 配置Tomcat服务器
3. 点击运行按钮

启动成功后，打开浏览器访问：

存储课程详细信息，是系统核心表之一。

| 字段名 | 数据类型 | 允许空 | 默认值 | 说明 |
|--------|----------|--------|--------|------|
| id | INT | 否 | 自增 | 主键，课程ID |
| course_no | VARCHAR(20) | 否 | - | 课程编号（唯一） |

| credit | DECIMAL(3,1) | 否 | - | 学分（如：3.0） |
| hours | INT | 否 | - | 学时 |
| type_id | INT | 是 | NULL | 课程类型ID（外键） |

#### 表9：course_selection（选课记录表）
记录学生的选课信息，关联学生和课程。

| 字段名 | 数据类型 | 允许空 | 默认值 | 说明 |
|--------|----------|--------|--------|------|
| id | INT | 否 | 自增 | 主键，记录ID |

#### 表10：score（成绩表）
存储学生的课程成绩。

| 字段名 | 数据类型 | 允许空 | 默认值 | 说明 |
|--------|----------|--------|--------|------|
| id | INT | 否 | 自增 | 主键，成绩ID |
| student_id | INT | 否 | - | 学生ID（外键） |
| course_id | INT | 否 | - | 课程ID（外键） |
| score | DECIMAL(5,2) | 是 | NULL | 成绩分数（0-100） |
| grade_point | DECIMAL(3,2) | 是 | NULL | 绩点（0-5.0） |
| update_time | DATETIME | 是 | 当前时间 | 更新时间 |

**唯一约束**：同一学生同一课程只有一条成绩记录

#### 表11：notice（公告表）
存储系统公告信息。

| 字段名 | 数据类型 | 允许空 | 默认值 | 说明 |
|--------|----------|--------|--------|------|
| id | INT | 否 | 自增 | 主键，公告ID |
| title | VARCHAR(200) | 否 | - | 公告标题 |
| content | TEXT | 是 | NULL | 公告内容 |
| publisher_id | INT | 是 | NULL | 发布者ID |
| publish_time | DATETIME | 是 | 当前时间 | 发布时间 |
| status | INT | 是 | 1 | 状态：1-显示，0-隐藏 |

| 字段名 | 数据类型 | 允许空 | 默认值 | 说明 |

#### 表13：course_review（课程评价表）★ 新增
存储学生对课程的评价信息，支持评分和文字评价。

| 字段名 | 数据类型 | 允许空 | 默认值 | 说明 |
|--------|----------|--------|--------|------|
| id | INT | 否 | 自增 | 主键，评价ID |
| student_id | INT | 否 | - | 学生ID（外键） |
| course_id | INT | 否 | - | 课程ID（外键） |
| rating | INT | 否 | 5 | 评分（1-5星） |

- 可以添加文字评价内容
- 教师可以查看自己课程的所有评价
- 系统自动计算课程平均评分

#### 表14：selection_log（选课日志表）★ 新增
记录学生的选课和退课操作历史。

| 字段名 | 数据类型 | 允许空 | 默认值 | 说明 |

- 不同操作类型使用不同颜色标识（选课-绿色，退课-红色）

### 6.5 课程封面图片Base64存储 ★

#### 功能描述
课程封面图片采用Base64编码存储在数据库中，解决了传统文件存储方式在服务器重启或重新部署后图片丢失的问题。

#### 技术实现
```java
// FileUploadUtil.java 核心代码
public static String uploadImage(Part filePart) {
    // 1. 获取文件类型
    String contentType = filePart.getContentType();
    
    // 2. 读取文件内容
    byte[] bytes = filePart.getInputStream().readAllBytes();
    
    // 3. 转换为Base64
    String base64 = Base64.getEncoder().encodeToString(bytes);
    
    // 4. 返回Data URL格式
    return "data:" + contentType + ";base64," + base64;
}
```

#### 数据库字段
```sql
cover_image LONGTEXT DEFAULT NULL  -- 存储Base64编码的图片数据
```

#### 优势
- 图片数据持久化存储
- 无需配置文件存储路径
- 部署迁移更加方便
- 支持多种图片格式（jpg, jpeg, png, gif, svg）

```
6. 验证成功：将用户信息存入 Session，跳转到对应首页
7. 验证失败：返回登录页，显示错误信息
```

### 7.2 学生选课流程
```
1. 学生登录后访问 course_list.jsp
2. StudentCourseServlet 查询可选课程列表
3. 学生点击"选课"按钮
4. 系统检查：
   - 选课功能是否开放
   - 课程是否还有名额
   - 是否已选过该课程
   - 是否有时间冲突
5. 检查通过：
   - 插入选课记录
   - 更新课程已选人数
   - 记录选课日志 ★
6. 返回选课结果
```

### 7.3 学生退课流程
```
1. 学生访问 my_courses.jsp 查看已选课程
2. 点击"退课"按钮
3. 系统执行：
   - 删除选课记录
   - 更新课程已选人数
   - 记录退课日志 ★
4. 返回退课结果
```

### 7.4 课程评价流程 ★
```
1. 学生在"我的课程"页面点击"评价"按钮
2. 弹出评价模态框
3. 学生选择评分（1-5星）
4. 填写评价内容（可选）
5. 提交评价
6. 系统保存评价记录
7. 教师可在"课程评价"页面查看
```

### 7.5 教师录入成绩流程
```
1. 教师登录后访问 score_courses.jsp
2. 选择要录入成绩的课程
3. 系统显示该课程的选课学生列表
4. 教师输入每个学生的成绩
5. 提交后，系统自动计算绩点并保存
```

### 7.6 管理员管理用户流程
```
1. 管理员登录后访问 student_list.jsp 或 teacher_list.jsp
2. 可进行以下操作：
   - 搜索：按学号/工号或姓名搜索
   - 添加：填写表单创建新用户
   - 编辑：修改用户信息
   - 删除：删除用户（会同时删除相关选课记录）
   - 重置密码：将密码重置为 123456
```

## 九、常见问题解答

### Q1: 数据库连接失败怎么办？
**A**: 请检查以下几点：
1. MySQL服务是否已启动
2. DBUtil.java 中的数据库地址、用户名、密码是否正确
3. 数据库 course_selection 是否已创建
4. MySQL驱动是否已添加到项目依赖

### Q2: 登录时提示"用户名或密码错误"？
**A**: 请确认：
1. 是否选择了正确的角色
2. 账号密码是否正确（默认密码都是 123456）
3. 数据库中是否有对应的用户数据

### Q3: 选课时提示"选课功能未开放"？
**A**: 管理员需要在"系统设置"中：
1. 开启选课功能开关
2. 设置正确的选课时间段（当前时间需在时间段内）

### Q4: 页面显示乱码怎么办？
**A**: 请确保：
1. 数据库字符集为 utf8mb4
2. 项目文件编码为 UTF-8
3. Tomcat 的 server.xml 中配置了 URIEncoding="UTF-8"

### Q5: 如何添加更多测试数据？
**A**: 可以通过以下方式：
1. 使用管理员账号登录，在后台添加
2. 直接在数据库中执行 INSERT 语句

### Q6: 课程封面图片不显示怎么办？
**A**: 请检查：
1. 图片是否已上传（数据库cover_image字段是否有值）
2. 图片格式是否支持（jpg, jpeg, png, gif, svg）
3. 如果是Base64格式，检查数据是否完整

### Q7: 成绩图表不显示怎么办？
**A**: 请确认：
1. 是否有成绩数据
2. 浏览器是否支持Canvas
3. Chart.js CDN是否可以访问

### Q8: 如何重新导入数据库？
**A**: 执行以下步骤：
1. 打开MySQL命令行或Navicat
2. 执行 `source /path/to/init.sql`
3. 脚本会自动删除旧数据库并重新创建

- **登录验证**：Session机制管理用户状态

# 在线课程选课系统 - 小白部署指南

本文档详细介绍如何在新电脑上从零开始部署运行本系统。

---

## 一、需要准备的软件

请按顺序下载安装以下软件：

| 软件 | 版本要求 | 下载地址 |
|------|----------|----------|
| JDK | 1.8 或更高 | https://www.oracle.com/java/technologies/downloads/ |
| Maven | 3.6 或更高 | https://maven.apache.org/download.cgi |
| MySQL | 5.7 或 8.0 | https://dev.mysql.com/downloads/mysql/ |

## 二、安装JDK（Java开发环境）

### 2.1 下载JDK
1. 打开浏览器，访问 https://www.oracle.com/java/technologies/downloads/
2. 选择 `Java 8` 或 `Java 17`
3. 选择 `Windows` → `x64 Installer`
4. 下载 `.exe` 安装文件

### 2.2 安装JDK
1. 双击下载的安装文件
2. 一直点击 `下一步`，使用默认安装路径（如 `C:\Program Files\Java\jdk1.8.0_xxx`）
3. 安装完成后点击 `关闭`

### 2.3 配置环境变量
1. 右键点击 `此电脑` → `属性` → `高级系统设置` → `环境变量`
2. 在 `系统变量` 中点击 `新建`：
   - 变量名：`JAVA_HOME`
   - 变量值：`C:\Program Files\Java\jdk1.8.0_xxx`（你的JDK安装路径）
3. 找到 `Path` 变量，点击 `编辑` → `新建`，添加：
   - `%JAVA_HOME%\bin`
4. 点击 `确定` 保存所有设置

### 2.4 验证安装
1. 按 `Win + R`，输入 `cmd`，回车打开命令行
2. 输入 `java -version`，回车
3. 如果显示Java版本信息，说明安装成功

---

## 三、安装Maven（项目构建工具）

### 3.1 下载Maven
1. 访问 https://maven.apache.org/download.cgi
2. 在 `Files` 部分，下载 `apache-maven-3.9.x-bin.zip`（Binary zip archive）

### 3.2 解压Maven
1. 将下载的zip文件解压到一个简单路径，如 `D:\Maven`
2. 解压后目录结构应该是 `D:\Maven\apache-maven-3.9.x\`
3. **注意**：路径中不要有中文和空格！

### 3.3 配置环境变量
1. 右键点击 `此电脑` → `属性` → `高级系统设置` → `环境变量`
2. 在 `系统变量` 中点击 `新建`：
   - 变量名：`MAVEN_HOME`
   - 变量值：`D:\Maven\apache-maven-3.9.x`（你的Maven解压路径）
3. 找到 `Path` 变量，点击 `编辑` → `新建`，添加：
   - `%MAVEN_HOME%\bin`
4. 点击 `确定` 保存所有设置

### 3.4 配置阿里云镜像（加速下载）
1. 打开Maven目录下的 `conf\settings.xml` 文件
2. 找到 `<mirrors>` 标签（大约在第146行），在其中添加：
```xml
<mirror>
  <id>aliyun</id>
  <mirrorOf>central</mirrorOf>
  <name>阿里云公共仓库</name>
  <url>https://maven.aliyun.com/repository/central</url>
</mirror>
```
3. 保存文件

### 3.5 验证安装
1. 按 `Win + R`，输入 `cmd`，回车打开命令行
2. 输入 `mvn -version`，回车
3. 如果显示Maven版本信息，说明安装成功

## 四、安装MySQL数据库

### 4.1 下载MySQL
1. 访问 https://dev.mysql.com/downloads/mysql/
2. 选择 `MySQL Installer for Windows`
3. 下载 `mysql-installer-community-8.0.xx.msi`

### 4.2 安装MySQL
1. 双击安装文件
2. 选择 `Custom`（自定义安装）
3. 在左侧选择 `MySQL Server 8.0.xx - X64`，点击箭头添加到右侧
4. 同样添加 `MySQL Workbench`（数据库管理工具）
5. 点击 `Next` → `Execute` 开始安装
6. 安装完成后点击 `Next` 进入配置

### 4.3 配置MySQL
1. 选择 `Standalone MySQL Server`，点击 `Next`
2. 保持默认端口 `3306`，点击 `Next`
3. 选择 `Use Strong Password Encryption`，点击 `Next`
4. **设置root密码**：输入 `root`（或你喜欢的密码，但要记住！）
5. 点击 `Next` → `Execute` 完成配置
6. 点击 `Finish` 完成安装

### 4.4 验证MySQL安装
1. 在开始菜单搜索 `MySQL Workbench`，打开它
2. 点击 `Local instance MySQL80`
3. 输入刚才设置的密码（如 `root`）
4. 如果能进入，说明MySQL安装成功

---

## 五、导入数据库

### 5.1 打开MySQL Workbench
1. 在开始菜单搜索 `MySQL Workbench`，打开
2. 点击 `Local instance MySQL80` 连接数据库
3. 输入密码（如 `root`）

### 5.2 导入数据库文件
1. 点击菜单 `File` → `Open SQL Script`
2. 选择项目文件夹中的 `sql/course_selection_backup.sql` 文件
   - **注意**：只需要导入这一个文件！不要导入init.sql
   - `course_selection_backup.sql` 包含完整数据和课程封面图片
3. 点击 `打开`
4. 点击工具栏的 ⚡ 闪电图标（或按 `Ctrl + Shift + Enter`）执行全部SQL
5. 等待执行完成（可能需要几秒钟，因为包含图片数据）

### 5.3 验证导入成功
1. 在左侧 `SCHEMAS` 面板，点击刷新按钮
2. 应该能看到 `course_selection` 数据库
3. 展开它，能看到多个表（admin、student、course等）

## 六、安装Tomcat服务器

### 6.1 下载Tomcat
1. 访问 https://tomcat.apache.org/download-90.cgi
2. 在 `9.0.xx` 版本下，找到 `Core` 部分
3. 下载 `64-bit Windows zip`（如 `apache-tomcat-9.0.xx-windows-x64.zip`）

### 6.2 解压Tomcat
1. 将下载的zip文件解压到一个简单路径，如 `D:\Tomcat`
2. 解压后目录结构应该是 `D:\Tomcat\apache-tomcat-9.0.xx\`
3. **注意**：路径中不要有中文和空格！

## 七、安装IntelliJ IDEA

### 7.1 下载IDEA
1. 访问 https://www.jetbrains.com/idea/download/
2. 下载 `Community`（社区版，免费）或 `Ultimate`（专业版，需激活）
3. 下载 `.exe` 安装文件

### 7.2 安装IDEA
1. 双击安装文件
2. 选择安装路径（默认即可）
3. 勾选 `Add "bin" folder to the PATH`
4. 勾选 `Create Desktop Shortcut` → `64-bit launcher`
5. 点击 `Install` 安装
6. 安装完成后启动IDEA

---

## 八、在IDEA中打开项目

### 8.1 打开项目
1. 启动 IntelliJ IDEA
2. 点击 `Open`（或 `File` → `Open`）
3. 选择项目文件夹 `course-selection-system`（包含pom.xml的那个文件夹）
4. 点击 `OK`
5. 如果弹出 `Trust Project`，点击 `Trust Project`

### 8.2 等待Maven下载依赖
1. IDEA会自动识别这是一个Maven项目
2. 右下角会显示下载进度
3. 等待所有依赖下载完成（首次可能需要5-10分钟）
4. 如果下载很慢，可以配置Maven镜像（见附录）

### 8.3 配置JDK
1. 点击菜单 `File` → `Project Structure`
2. 左侧选择 `Project`
3. 在 `SDK` 下拉框选择你安装的JDK（如 `1.8`）
4. 如果没有，点击 `Add SDK` → `JDK`，选择JDK安装路径
5. `Language level` 选择 `8`
6. 点击 `OK` 保存

### 8.4 配置Maven（重要）
1. 点击菜单 `File` → `Settings` → `Build, Execution, Deployment` → `Build Tools` → `Maven`
2. 在 `Maven home path` 选择你安装的Maven路径（如 `D:\Maven\apache-maven-3.9.x`）
3. 在 `User settings file` 勾选 `Override`，选择 `D:\Maven\apache-maven-3.9.x\conf\settings.xml`
4. 点击 `OK` 保存
5. 在IDEA右侧找到 `Maven` 面板，点击刷新按钮重新下载依赖

## 九、配置数据库连接

### 9.1 修改数据库配置
1. 在IDEA左侧项目目录中，找到并打开文件：
   `src/main/java/com/course/util/DBUtil.java`
2. 找到以下代码（大约在第10-12行）：
```java
private static final String URL = "jdbc:mysql://localhost:3306/course_selection?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8";
private static final String USERNAME = "root";
private static final String PASSWORD = "root";
```
3. 如果你的MySQL密码不是 `root`，把 `PASSWORD` 改成你的密码
4. 按 `Ctrl + S` 保存文件

## 十、配置Tomcat服务器

### 10.1 添加Tomcat配置
1. 点击IDEA右上角的 `Add Configuration`（或 `Current File` 下拉框）
2. 点击左上角 `+` 号
3. 选择 `Tomcat Server` → `Local`
   - 如果没有这个选项，说明你用的是社区版IDEA，需要安装插件（见9.2）

### 10.2 社区版IDEA安装Smart Tomcat插件
1. 点击 `File` → `Settings` → `Plugins`
2. 搜索 `Smart Tomcat`
3. 点击 `Install` 安装
4. 重启IDEA
5. 重新点击 `Add Configuration` → `+` → `Smart Tomcat`

### 10.3 配置Tomcat路径
1. 在配置窗口中：
   - `Name`：输入 `Tomcat`
   - `Tomcat Server`：点击 `Configure`，选择Tomcat解压路径（如 `D:\Tomcat\apache-tomcat-9.0.xx`）
   - `Deployment Directory`：选择项目的 `src/main/webapp` 目录
   - `Context Path`：输入 `/course`
2. 点击 `OK` 保存

### 10.4 专业版IDEA配置（如果是专业版）
1. 在Tomcat配置窗口，点击下方 `Deployment` 标签
2. 点击 `+` → `Artifact`
3. 选择 `course-selection-system:war exploded`
4. `Application context` 输入 `/course`
5. 点击 `OK` 保存

## 十二、常见问题解决

### 问题1：Maven依赖下载失败
**解决方法**：配置阿里云镜像
1. 找到Maven配置文件（通常在 `C:\Users\你的用户名\.m2\settings.xml`）
2. 如果没有这个文件，创建一个
3. 添加以下内容：
```xml
<settings>
  <mirrors>
    <mirror>
      <id>aliyun</id>
      <mirrorOf>central</mirrorOf>
      <url>https://maven.aliyun.com/repository/central</url>
    </mirror>
  </mirrors>
</settings>
```
4. 在IDEA中点击 `File` → `Invalidate Caches` → `Invalidate and Restart`

### 问题2：数据库连接失败
**解决方法**：
1. 确认MySQL服务已启动（在服务中查看 `MySQL80` 是否运行）
2. 确认DBUtil.java中的密码与你的MySQL密码一致
3. 确认数据库 `course_selection` 已导入

### 问题3：Tomcat启动失败，端口被占用
**解决方法**：
1. 按 `Win + R`，输入 `cmd`
2. 输入 `netstat -ano | findstr 8080`
3. 记下最后一列的PID数字
4. 输入 `taskkill /PID 数字 /F` 结束占用进程
5. 重新启动Tomcat

### 问题4：页面显示404
**解决方法**：
1. 确认访问地址是 `http://localhost:8080/course/login.jsp`
2. 确认Tomcat的Context Path配置为 `/course`
3. 检查webapp目录下是否有login.jsp文件

### 问题5：中文乱码
**解决方法**：
1. 点击 `File` → `Settings` → `Editor` → `File Encodings`
2. 将所有编码设置为 `UTF-8`
3. 勾选 `Transparent native-to-ascii conversion`
